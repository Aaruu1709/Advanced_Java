# 🚀 Advanced Java Tutorials

This repository contains my hands-on practice and notes on **Advanced Java concepts**, implemented using Java and developed in IntelliJ IDEA.

---

## 📚 Topics Covered

* Multithreading & Concurrency

  * Thread creation
  * Synchronization (`synchronized`)
  * Locks (`ReentrantLock`)
  * Semaphores
  * Executor Framework

* Java Collections Framework

  * List, Set, Map
  * Concurrent Collections

* Exception Handling

* File Handling (I/O & NIO)

* JDBC (Database Connectivity)

* Lambda Expressions & Functional Interfaces

---
